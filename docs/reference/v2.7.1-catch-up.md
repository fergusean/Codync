# v2.7.1 catch-up

The consolidated branch adopts [upstream v2.7.1](https://github.com/leepokai/Codync/releases/tag/v2.7.1). Desktop macOS and Linux now share Electron/React in `apps/desktop/`; the iOS Swift package moved to `apps/ios/Kit/`. The old Mac and GTK clients were removed upstream.

On October 5, upstream `main` (`e6feb1d`) was merged into consolidated and the fork main was fast-forwarded. PRs #23 and #26 were initially closed because their native Mac implementations were removed upstream, then reopened with their Electron ports at Sean’s request. Their original branch tips were temporarily restored to allow reopening; only after reopening were the port commits pushed with lease protection. Titles and descriptions now target the Electron desktop implementation on main. PRs #27, #31, #33 and #40 were rebased onto current main and pushed with lease protection.

The Dock, remote-startup, routine typography, animation and bot-bubble branches now contain their useful Electron/iOS/TUI changes on current main. Superseded activation diagnostics, conversation rendering and native screenshot branches were aligned with main. Their original tips, and every rewritten feature branch tip, remain under local `backup/pre-main-20261005/` refs.

## Other local patches

Bot requests and replies retain blue bubbles and attribution on iOS, Electron desktop and the TUI. Completed recipient replies suppress duplicated notice excerpts. Routine names retain matching bot typography. Mac SwiftUI retained-row fixes, AppKit rendering tests, GTK animation patches and activation diagnostics are obsolete with those renderers removed. The iOS avatar animation improvements remain.

Uncommitted Android/Windows code, cloud device migrations, FCM support and host device/activity changes were preserved. Windows device icons moved to the desktop approval/device views. Windows is not yet superseded: upstream Electron currently packages macOS/Linux and does not implement the native Windows client’s encrypted direct/relay transport. Its native security and SSH helpers remain. The pre-upgrade recovery stash remains available; development work stays separate from the release integration commits.

## Deployment boundaries

The rdev service keeps its existing identity, database, systemd unit and private cloud/push overrides. Worker source was unchanged by v2.7.1, so this release needs no new Worker deployment. The local Mac replacement preserves account configuration and migrates saved SSH, Dock, host and updater preferences; see [local upgrades](../guides/local-upgrades.md). Android and Windows are private native clients and remain separate from upstream's desktop replacement.
